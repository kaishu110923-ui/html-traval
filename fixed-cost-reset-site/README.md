# 固定費リセット

一人暮らし・新生活向けの固定費見直しMVPサイトです。

## カテゴリー

生活改善 / 固定費見直し / 一人暮らし

## アイデア

比較サイトを何個も開く前に、スマホ、電気、ネット、サブスクのどれから見直すべきかを3分で診断するサイト。

## 検証したい行動

- トップページから診断へ進むか
- どの固定費カテゴリがクリックされるか
- 診断結果を受け取るボタンを押すか
- メール登録フォームまで進むか

## ファイル

- `index.html`: サイト本体
- `styles.css`: デザイン
- `app.js`: 診断、モーダル、CTAクリック計測
- `assets/expense-dashboard.svg`: ヒーロービジュアル

## 見方

`index.html` をブラウザで開くと、そのまま動きます。
