# Japan Prefecture Travel Guide

外国人旅行者向けに、47都道府県それぞれのおすすめスポット、ルート案、旅行計画メモを紹介する1ページ旅行ガイドです。

## 目的

訪日旅行者が、定番ルート以外の都道府県も比較しながら旅行先を選べるようにすることを目的にしています。

## ファイル

- `index.html`: 1ページサイト本体
- `styles.css`: レイアウトとデザイン
- `script.js`: 47都道府県データ、地域フィルター、検索、多言語切り替え

## 対応言語

- English
- 日本語
- 中文
- 한국어
- Français
- Italiano

## コンテンツ方針

- 旅行者にとって実用的な情報をページ内に置く
- 作成中、空ページ、ナビだけの画面に広告が出ない構成にする
- 予約前に公式情報を確認する案内を入れる
- 広告よりも本文コンテンツを優先する
